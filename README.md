# Data Analyzer
# Overview
## This repository contains a simple Python script used to analyze and process a set of basic data. The script evaluates a set of 5 values and computes the total number of values, the maximum reading, the minimun reading and the average of all values.

## Data used 
The script uses the following set of values:
[22, 24, 26, 28, 30]
