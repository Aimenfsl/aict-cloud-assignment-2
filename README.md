# Sensor Data Analyser
## Overview
This repository contains a simple Python script used to analyze and process a set of basic sensor data. The script evaluates a set of 5 values and computes the total number of values, the maximum reading, the minimum reading and the average of all values.

##  Sensor Data used 
The script uses the following set of values:

[22, 24, 26, 28, 30]

## What each line of code does 

**len(readings)**: Computes the total number of values in a set.

**min(readings)**: Gives the smallest recorded value in a set.

**max(readings)**: Gives the largest recorded value in a set.

**sum(readings)/len(readings)**: Sums up all the values and divides it by the count to give the average.
