# Sensor Data Analyser
## Overview
This repository contains a simple Python script used to analyze and process a set of basic sensor data. The script evaluates a set of 5 values and computes the total number of values, the maximum reading, the minimum reading and the average of all values.

##  Sensor Data used 
The script uses the following set of values:
[22, 24, 26, 28, 30]

## Instructions on how to run the Python script
Download the Python file from this repository .
Go to google colab [colab.research.google.com] and upload the notebook.
Click on the **run** icon or simultaneously press **shift+enter** to execute the code on colab.
